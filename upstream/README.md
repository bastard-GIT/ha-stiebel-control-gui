# Upstream files (vendored)

## Purpose

Verbatim copies of selected files from the upstream project. They are the source
of the generated Elster table used by the GUI (`gui/upstream_table.py`, generated by
`tools/gen_upstream_table.py`). The GUI only reads these files; it never executes or
modifies them.

## Updating the pin

1. Replace the files unchanged with the versions from the new upstream commit (`git show <commit>:esphome/ha-stiebel-control/<path>`, byte-identical).
2. Update `PIN.json` (`commit`, `date`, `files` with SHA-256 of each file).
3. Regenerate and test: `python tools/gen_upstream_table.py --all`, then `tests/test_upstream_table.py` for all models. Review changes in signal count and preprocessor expressions.
4. Do not edit these files by hand. The hash check fails otherwise.
